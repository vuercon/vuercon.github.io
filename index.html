我的第一篇博客

如何建立一个Blog

Hexo + GitHub Pages 搭建个人博客【小白完整版全流程】

环境：Windows，Node放D盘，Hexo博客项目放在 D:\blog
最终效果：线上可访问的静态博客：https://你的用户名.github.io
本次示例用户名：vuercon

前置准备清单

  1. 注册 GitHub 账号（记住你的用户名！仓库名字必须和它强绑定）
  2. 下载两个软件：Node.js、Git
  3. 推荐编辑器：IDEA / VS Code（用来改配置、写文章）

一、安装 Node.js（提供npm包管理器，Hexo依赖它）

  1. 打开 Node.js 官网，选择 Windows .msi 安装包（不要zip免安装版）
  2. 双击msi启动安装
    • 到选择安装路径页：点Browse，改成D盘，例：D:\nodejs
    • ✅ 路径要求：无中文、无空格，禁止类似 D:\Node 软件
    • ✅ 全程保持勾选 Add to PATH（添加环境变量），不要取消！
    • 一路Next完成安装
  3. 安装完成：关闭所有已经打开的CMD/PowerShell，重新新开一个终端（必须重启终端，环境变量才生效）
  4. 校验是否安装成功，终端输入：

✅ 正常输出版本号=成功；提示不是内部命令=环境变量勾选失败，重装。

二、安装 Git（用来提交代码、推送到GitHub）

  1. Git官网下载 Windows 64位安装包
  2. 双击安装，重点选项：
    • 勾选：Git from the command line and also from 3rd-party software（加到系统PATH）
    • 其余选项全部默认，一路Next
  3. 新开终端校验：

✅ 输出版本号即成功。
4. 配置Git身份（只需要执行一次，替换成你自己GitHub信息）

三、全局安装 Hexo 命令行工具 hexo-cli

终端任意目录执行：

-g = 全局安装，Node装在D盘也不受影响
输出 added xx packages 代表成功；warn黄色警告不用管，不影响使用

  1. 校验Hexo：

✅ 输出版本信息=hexo安装完成

四、初始化Hexo博客项目（放在D盘blog文件夹）

  1. 终端切换到D盘，新建并进入blog文件夹

执行完上面，你的终端前缀会变成 D:\blog>，代表位置正确

  1. 初始化Hexo骨架

它会自动拉取基础模板，等待跑完，不要中途关掉窗口

  1. 安装项目依赖包（init完成后必须跑）
  1. ✅ 本地预览测试（可选，确认博客本地能跑）

打开浏览器访问 [http://localhost:4000](http://localhost:4000)，看到Hello World页面就正常。

停止本地预览：终端按 Ctrl + C

五、安装Git部署插件（hexo-deployer-git，用来推送到Github）

保持在 D:\blog 目录，执行：

六、去GitHub新建专属博客仓库（非常关键！名字不能错）

  1. 登录GitHub，右上角点 New repository 新建仓库
  2. 填写参数（严格遵守）
    • Repository name：你的用户名.github.io（示例：vuercon.github.io）
    • 仓库权限：Public（公开免费）
    • ❌ 不要勾选 Add a README file
    • 其余全部空着，点 Create repository 创建

      ⚠️ 仓库名字错一个字符，后面部署就会报 Repository not found

七、修改Hexo核心配置文件 _config.yml

  1. 用IDEA/VS Code打开 D:\blog\_config.yml
  2. 滚动到文件最末尾，找到deploy配置块，全部替换为下面内容

✅ YAML语法铁则：冒号 : 后面必须跟一个空格，否则直接报错
示例（你的情况）：repo: [https://github.com/vuercon/vuercon.github.io.git](https://github.com/vuercon/vuercon.github.io.git)

  1. Ctrl+S保存文件

八、部署上线（上传博客到GitHub Pages）

保持终端在 D:\blog>，两条命令依次执行

  • hexo g = hexo generate：生成静态网页文件（public文件夹）
  • hexo d = hexo deploy：自动git推送、部署到Github

    执行hexo d会自动弹出浏览器，登录你的GitHub账号，完成授权
    ✅ 看到 deploy done 字样，代表部署成功！
    👉 线上访问地址：https://你的用户名.github.io
    刚上传后，GitHub同步需要几十秒~2分钟，打不开就多刷新几次

日常使用流程（以后写文章只需要这一套）

  1. 打开终端，进入博客目录
  1. 新建一篇文章（引号里是文章标题，支持中文）

文件自动生成在 D:\blog\source\_posts\文章标题.md

  1. 用编辑器打开这个.md文件，写Markdown内容（标题、文字、图片、列表）
  2. 写完保存，重新生成+部署更新网站
  1. 刷新 https://你的用户名.github.io，就能看到新文章

高频常备命令表（收藏）

命令 作用
hexo s 本地启动预览，localhost:4000，写完先本地看效果
hexo new "标题" 新建文章
hexo clean 清理缓存！页面错乱、样式异常优先跑这个
hexo g 生成静态页面
hexo d 部署上传到GitHub
hexo g && hexo d 生成+上传一键组合命令

  2. 配置图床，在文章里放图片

1. `hexo new "标题"`
2. 打开 md 写笔记
3. `hexo s` 本地预览，检查排版
